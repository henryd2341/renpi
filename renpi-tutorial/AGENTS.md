# Ren’Pi 项目约定

- 本项目制作 Ren’Pi 使用教程；引导角色名为 **Salome**，产品名为 Ren’Pi。已确认采用现有角色与深蓝/珊瑚 GUI，字体为用户提供的 Noto Serif SC。
- 开始新任务先读 [公开维护说明](README.md)，核对正文入口、文件职责和维护边界。初始化已由用户确认结束；本地 `authoring/handoff/` 若存在，仅在需要历史决定或本轮限制时按需查阅，缺失不视为项目未初始化。
- 正式制作读取 `renpi-coding/code-renpy-game/SKILL.md` 及本轮适用链接；读取当前程序任务和有效路线，再制作所选单元。保留玩家决定空间和稳定锚点/选项。
- 运行内容在 `game/`，创作源在 `authoring/shared/tutorial/`；当前已有基础安装，后续复用而非重新初始化。`start-game.cmd` 是正式启动入口。
- 测试和运行按用户当前授权及交接中的限制执行；历史未执行项不作为通过证据。任务、分支、候选、接入与加载结果以公共程序当前记录为准。
