# Ren’Pi 教程：公开维护说明

本目录是 Ren’Pi 仓库内的教程项目，由 Salome 引导用户阅读开场、选择方向，再通过公共桥接制作和接入故事分支。SDK、模型认证和本机运行状态由使用者自行准备；它不是独立分发包。

## 启动与连接

在仓库根目录的 PowerShell 中执行：

```powershell
# 获取正式运行素材的 LFS 实体文件，需要访问仓库的 LFS 服务。
git lfs pull --include="renpi-tutorial/game/**"
$env:RENPY_HOME = Read-Host '请输入已安装的 RenPy SDK 完整目录'
.\renpi-tutorial\start-game.cmd
```

[正式启动器](start-game.cmd)使用 SDK 自带的 Windows Python，检查 SDK 路径、开场入口及未完成的基础安装记录。异常时查看教程根目录的 `log.txt`、`traceback.txt`；启动器仅启动已接入内容。

真实续写另需在本教程目录运行匹配版本的 Pi 与仓库公共扩展，配置模型，并通过 `/renpi-status` 核对连接。首次建立本机桥接使用 `/renpi-setup`；已有安装优先复用。连接、候选接入和重载规则见[公共桥接契约](../skills/renpi-coding/references/bridge-contract.md)。

## 修改教程

1. **先核对创作源与运行版。** 明确本次修改范围，比较对应 RPY 的差异，保留后续有效修改，再按现有接入流程处理。维护旧项目时复用基础安装，避免用旧稿覆盖运行版。当前 `opening.rpy`、`options.rpy` 两侧存在差异，尚待单独整理。
2. **保留稳定入口。** 开场由 `start` 调用 `rp_tutorial_opening`；选择点为 `tutorial.first_story`，选项 ID 为 `study_warm`、`rain_mystery`。修改显示文案时保留这些标识；确需调整时核对调用方和已有分支。
3. **界面修改集中在项目呈现层。** 修改 screen、style 或资产；请求、分支、候选采用与加载确认由公共桥接负责。像素定位同时核对 anchor，编译通过之外还需对应的布局证据。
4. **按明确范围验证。** 区分静态检查、引擎 compile/lint、GUI 阅读和真实生成闭环。只有与当前源码匹配的检查结果才作为证据；临时执行限制按当前任务及适用的本地记录确认。

基础安装、候选与运行状态以程序记录为准。维护说明不保存项目身份、任务 ID、连接凭据或某次运行的状态快照。

## 公开提交边界

- 跟踪当前有效代码、必要维护源码、实际使用素材及许可证；图片、音频、字体按仓库 `.gitattributes` 使用 Git LFS，新增格式先核对规则覆盖。
- 生成提示词、模型工作流、会话交付、原始草稿、重复素材、预览图及本机验证产物按现有忽略规则保留在本地；采用逐项放行，避免整体公开创作区。
- LFS 不负责元数据清理。提交图片时同时检查嵌入的提示词、工作流及其他元数据；私有原件与公开素材分开保留。
- 以公开文件和当前源码说明维护流程。需要追溯本地过程时，再按需读取已有交接记录；记录缺失不等于项目需要重新初始化。

## 开发工具与验收边界

- [隔离预览入口](start-preview.cmd)供已有本地验证工程使用，不是正式启动入口。其准备脚本仍读取创作区字体等材料，当前克隆内容不保证覆盖这些本地输入；运行前先核对输入和链接。
- GUI 构建脚本会覆盖同名 PNG、SVG 和预览，并依赖本地 `sharp` 及创作区背景/立绘。重新导出前先保留手工修改、核对依赖；公开源码存在不等于构建流程已验证可复现。
- 历史报告只代表各自版本。完整 GUI 阅读、真实生成分支的采用与重载、加载确认及打包分发，分别按当前版本验收；本说明不声明这些检查已完成。
