# 制作图像素材

主要交付剧情所需的场景插图与补充图：把明确的一刻、环境、人物关系或局部细节画清楚。也可在 init 尚未完成时提前准备所需图片；本技能没有“整个 init 完成后才能调用”的前置条件。

先读 [Image 边界](../references/image-contract.md)。按阶段加载下列技能，保留现有有效成果，不为换阶段重新生成同一份素材。

| 顺序 | 技能 | 完成条件 |
| --- | --- | --- |
| 1 | [读取图像任务](../read-image-brief/SKILL.md) | 用途、画面时刻、依据、参考图角色与输出归属明确；已有图已检查复用条件 |
| 2 | [确认后端与模型](../resolve-image-pipeline/SKILL.md) | 实际后端、模型/版本、工作流/能力及可填写字段相互匹配 |
| 3 | [编写模型专属提示](../compose-image-prompt/SKILL.md) | 提示语法与模型匹配，内容约束可回查，参数保持正确归属 |
| 4 | [执行图像制作](../produce-image-assets/SKILL.md) | 新图/编辑或复用结果已取回到分配位置，作业与来源明确 |
| 5 | [检查并交付素材](../review-image-assets/SKILL.md) | 技术与视觉分别核对，推荐图/差分用途及待处理项明确，交 Coding 整合 |

只有导入/复用且无需生成或编辑时，可从任务确认进入文件交付检查，跳过模型及提示词步骤。结果需要编辑则回到相应模型/后端路线，保留原图。

## init 提前调用与后续复用

- Coding 可在 init 中按已明确的一项图片需求委派，无需等齐其他素材、完整剧情、GUI 代码或整个环境清单；只核对该任务实际依赖。
- 没有已确认视觉基准时，将本次任务明确为“制作基准候选”；展示后由 Coding 取得用户方向确认，再扩展同风格差分。已有基准直接复用，不每张重问。
- 提前产物沿同一资产用途及来源记录交接，后续 init/剧情任务先核对再复用。共享基础图与分支专属 CG 分开归属，不为一张提前生成的图创建虚构分支或推进剧情状态。
- 尚在生成或结果不明时，后续任务引用并核对原作业，不重复提交。基准或剧情后来变化，只重审受影响的图，保留其余成果及既有任务目标。

## 收口

交付图片而非只有提示词；用户明确只要提示或当前制作能力缺失时，准确交付提示准备结果与缺口，图像任务仍保留其真实状态。图片交付与游戏已接入、init 已完成是不同结论。

提示词、图像编辑与局部返修沿既有任务次数约束执行，重点修正具体偏差，不无限抽图。Image 提出协作需求，由 Coding 安排，避免自行派生递归专业 Agent。
