# 其他 API 与宿主内建图像工具

适用：已选后端既非直接 ComfyUI 工作流，也非 NovelAI。先确认具体工具/供应商，保留用户指定来源，不为追求统一代码而强行换成另一个 API。

## 只填写真实接口

- 读取当前工具 schema 或供应商文档，核实生成/编辑、模型 ID、参考图与遮罩的实际传递方式。自然语言任务说明中的尺寸、背景或质量不自动等于 API 参数。
- API 公开的能力与宿主工具暴露的能力分开：内建工具可能只收 prompt/引用图片，并隐藏实际模型选择；此时按公开接口调用，记录模型未公开，不声称选中了用户所列某个确切版本。
- 后端支持同步结果、异步作业、文件或临时 URL 时分别按真实结果处理。保留返回身份与来源，仅下载该工具提供且确属本次的结果，复制正式资产进项目。
- 负面字段、seed、透明输出、mask、尺寸和参考数量逐项查证；字段未公开就省略，不把 ComfyUI 的 CFG/steps 或 NovelAI 的加权语法硬塞进去。

## 宿主内建工具

实际选用内建图像工具时，加载宿主已提供的图像技能并遵循当前工具说明；普通请求按宿主默认工具路径执行。只有任务明确选择其他已配置后端时才使用相应入口，技能编写本身不触发生图。

本地编辑目标先查看，按当前工具支持的引用路径或会话图像机制传入；生成后实际检查并保存项目所需文件。工具默认存储区和会话预览不替代项目资产交付。

## 新后端

首次使用只补齐当前任务必要的信息：实际接口及版本、支持动作/字段、模型身份、参考与输出、状态查询/取消边界。已有能力缺失时交 Coding 协调，不在本技能里编写新适配器或后台服务。确认后仍使用选定模型的独立提示指南。
