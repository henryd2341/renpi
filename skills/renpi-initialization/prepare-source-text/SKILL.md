# 整理原文与有序分片

进入条件：采用的来源版本、整理范围与改编忠实度已明确，相关工作已列入确认的筹备方案。读取 [项目边界](../references/project-contract.md)。扫描阶段只诊断，确认方案后才生成整理结果。

## 保留来源，确定可读文本

1. 逐份登记原文件、来源版本、文件顺序和覆盖范围；原文件保持原样。已有合格分片和索引时核对后复用，只处理缺口。整理结果置于既有资料区；新布局可用 `authoring/sources/<来源标识>/`，与原件分开。
2. 区分纯文本与 PDF、DOCX、扫描图等来源。后者先用当前可用的提取/OCR 能力生成带页码或段落来源的文本，抽查多栏、页眉、断行与顺序；提取存疑处单独记录，保留原件供核对。
3. 编码优先采用 BOM 和已知导出信息，再严格尝试 UTF-8；失败后依据来源检查已知编码候选，如 GB18030。成功解码不等于文字正确，检查开头、中段、结尾及异常位置。候选有歧义时展示样例请用户确认；解码错误保留位置与诊断，完整结果生成前解决，不用忽略错误或替换字符掩盖丢字。
4. 在派生副本中统一为 UTF-8（无 BOM）、LF 换行，记录原编码与 CRLF/CR/LF 情况。仅做这些已声明的机械变换；段落空行、缩进、标点、繁简、正文和末尾换行保留。OCR 修字、合并断行或删除页眉是另一项内容整理，记录对应来源及依据。

完成标志：原件可回查，文本可正确阅读，派生文本与原件之间的变换及未决缺口明确；必需内容仍有解码/提取缺口时保持待处理。

## 识别边界，再切分

按 [分片规则](references/splitting-rules.md) 执行候选扫描与切分。

- 先正则扫描整份规范化文本的常见章节、卷/部、独占行分隔符，生成“位置—标题/标记—候选类型”预览；结合上下文排除目录条目、引用和重复页眉。存在章节体系时优先按其层次组织。
- 将候选判断和自动切分规则写入整理记录。规则明确时按已确认范围自动处理；会改变内容顺序、选用版本或把有歧义段落归入不同章节时，携具体位置询问，而不是让用户逐条审核所有正常标题。
- 章节过大时在章内按段落拆子片；没有标题时用段落边界。根据实际读取工具的单次限制留余量，注明度量单位，字符数不冒充 token 数。单段超过限额时优先用可靠句界；仍存疑则保留大段，避免硬截、摘要或丢弃。只有实际验证过按来源位置分段读取、可以完整取回该段，才将其记为可用的超限例外；否则保持待处理。
- 每个字符仅归属一个分片。标题与分隔符通常随其后正文，序言、目录、附录与尾注也纳入覆盖，不因不属于正文章节就删除。资料分片大小不决定游戏单元长度。

完成标志：采用的边界及层次清楚，分片大小适合读取，超限例外有已验证的完整读取方式；本次必需来源不存在未处理的读取缺口，技术切分没有改写原作。

## 交付与完整性核对

优先沿用现有格式；没有时交付以下三项：

| 产物 | 必需内容 |
| --- | --- |
| 规范化全文 | `normalized.txt`；用于完整性比对的派生文本 |
| 有序分片 | `parts/000001-<短标题>.txt` 等；序号宽度覆盖总数，标题清理非法路径字符，序号保证同名不冲突 |
| 来源索引 | `source-index.json` 或等效现有索引；原文件与版本、编码/换行变换、提取方式、分片次序/路径/标题/父章节、规范化文本范围、原件定位、采用规则、覆盖缺口 |

规范化位置与原始字节位置分开表达。纯文本可映射原行号；提取/OCR 资料保留页码或段落映射及精度，位置不精确时如实注明。

发布前实际检查：

1. 按索引顺序拼接分片，逐字符等于规范化全文；检查范围连续、无重叠、无缺口，文件列表与索引一致。
2. 核对首尾、序言/附录、标题边界及异常分片，确认每个原文位置的标题与分隔符恰好保留一次；原文中同名标题或重复内容照原样保留，不按文本值去重。另抽查原件对应位置，避免只证明“分片忠实于错误提取结果”。
3. 核对原件未变（可用处理前后摘要）；在独立输出目录完成校验后再更新有效索引。已有采用版本继续保留，避免失败时留下半套新索引或覆盖正在使用的资料。

将实际检查结果、已读/待读范围和首个单元拟用位置交回 [基础准备](../prepare-foundation/SKILL.md)。全篇切分完成不等于全篇语义阅读、校对或改编完成。
