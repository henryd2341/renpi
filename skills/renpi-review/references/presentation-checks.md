# 演出审查：按变更选择

这是问题定位表，不要求每次跑全部项目。检查项目继承本轮已确认要求及 [Coding 演出配方](../../renpi-coding/references/presentation-recipes.md)。不强制重新生图、制作素材或改变已确认视觉方向。

| 对象 | 要看什么 | 哪种证据支持结论 | 常见问题归属 |
| --- | --- | --- | --- |
| 背景/CG/补图 | 画面时刻、人物/道具/衣着、视角、剧透、构图安全区 | 当前素材像素＋本轮剧情/基准；布局再对实际场景 | 画面内容问题交 Image；选错图、触发位置或裁切问题交 Coding |
| 透明立绘/表情 | 真 alpha、边缘/烘焙棋盘格、差分一致、可见包围盒、站位和脚底基线 | 素材技术结果＋图像观察；比例/遮挡看实际 GUI | 源图缺透明交素材制作；拉伸、错表情/tag、文字框挡脸交整合 |
| 图像生命周期 | scene 清层、同 tag 替换、transform 保留/重置、离场残留 | RPY 调用与实际入场、切换、离场观察 | 多人同 tag 冲突、退 CG 后人物丢失或幽灵立绘 |
| 说话者聚焦 | Character/tag/别名映射、在场范围、明暗渐变、分段与等待点击、无焦点规则 | 对照当前句与连续画面；加载/回退到具体句子 | A 发言却亮 B、打完就熄灭、同角色每句闪暗、旁白错误聚焦或泄露身份 |
| 文字渐显 | 有效速度、say screen、局部样式/标签、点击补全、设置和保存偏好 | 有限速度与即时速度下的操作记录及连续观察 | 偏好被反复覆盖、设置无效、补全文顺带跳句、逐字音效残留 |
| 音乐/环境音/音效/语音 | 曲目与触发、循环/续播、音量/静音、淡入淡出、跨单元延续/停播 | 使用表＋实际调用＋试听结果；日志仅证明命令 | 用途未定先补编排；同通道互相截断、退场不停、同曲反复重启 |
| ATL/转场 | 起终态、切表情重播、parallel 属性竞争、skip/auto/rollback 后状态 | 代码＋时间序列/运行观察 | 一张截图只覆盖一个时刻，不证明动画/跳过正常 |
| GUI/交互 | 基准一致、字体/长文本、焦点/键鼠、遮挡、窗口适配、Return 接续、临时 screen 清理 | 当前版本真实页面及对应操作证据 | SVG 方向图不证明 Ren’Py 控件已实现；点击日志不证明正确阅读位置 |

## 动态验收场景

下表由 Coding 自验与 Review 共用；按实际变更选项，每个适用场景给出结果，不适用项写原因。首次接通三项基线时组合为“入场 → A/B 交替 → 同角色连续句 → 旁白 → 换表情 → 一人离场”的隔离短场景，或复用现有等价片段。测试用分段、群体发言等边界可放隔离副本，保留正式原文。

| 编号 | 操作与触发条件 | 可观察的预期结果 |
| --- | --- | --- |
| P01 发言切换 | A/B 同屏，A 发言后切 B；两句都等待打字完成再点击 | 焦点对应当前发言者；渐显结束到点击之间保持；切换不闪白或影响站位 |
| P02 连续与分段 | 同角色连续句；适用时使用带 `{w}`/`{p}` 的台词 | 分段和连续发言不重复入场/反复闪暗；继续键与停顿按原生语义工作 |
| P03 无焦点与身份 | 进入旁白或画外发言；群体/匿名发言仅在项目存在或映射受影响时检查 | 按采用规则恢复或转移焦点；无错误人物关联，未公开身份保持隐藏 |
| P04 出入与换脸 | 人物进入、同 tag 换表情、移位、hide 退出，再 scene 清场；按场景取适用动作 | 出入符合所选过渡；换脸保留站位/焦点且不重播入场；清场无残留，无半透明卡住 |
| P05 渐显与点击 | 用有限速度显示长中文，文字途中点击，再点击继续；切为即时显示 | 第一次补全当前可见文本段，第二次正常推进；文字无遗漏/溢出，即时模式立即可读 |
| P06 偏好与升级 | 调速后重新进入/重启；有默认值变更时另用既有持久化数据副本验证 | 设置生效并按约定保留；默认值迁移结果与本轮明确选择一致；正式存档/偏好未被清空 |
| P07 快进与自动 | 在入场/渐显/发言切换中启停快进，再自动播放；沿用减少动态选项 | 角色最终位置、明暗、在场状态和文字正确，操作仍可用；自动等待按设置，无意外强制停顿 |
| P08 保存与恢复 | 在 A/B 对话等待时保存，推进并改变焦点后读取；向前句回退；重入场景 | 恢复句与焦点/表情/站位一致，无未来状态残留；没有重复入场或异常慢速重播；已有存档涉及修订时另查兼容 |
| P09 音画联动 | 仅在启用文字音效、配音或持续微动时：补全文、跳过、静音、离场、减少动态 | 音效按自身生命周期停止，焦点保留正确；减少动态后仍可辨认人物并阅读 |

保存候选版本/关键文件依据、SDK、真实入口、测试时偏好、实际操作、预期与实际结果及证据路径。动画用录屏、带时间顺序的采样或可信现场观察记录；单张截图只支持静态外观，脚本/播放日志只支持调用发生。新的共用定义变动使受影响旧证据失效，既有原型或单角色样例的通过结果不替代本表。

## 问题判定

- 本轮采用基线却缺少对应实现，或已观察到错误焦点、换脸重入场、渐显/恢复异常：记录具体缺陷，交 Coding 修复。
- 实现存在但必要的时序/交互/恢复证据缺失：列出最小补验项，按既有判定规则处理证据门槛，静态通过单列。
- 已确认的硬切、即时显示、等亮群像和减少动态符合其适用范围：按该约定验收；呼吸、眨眼或更复杂镜头保持可选建议。

对素材来源或生成记录存疑时按 [Image 检查约定](../../renpi-image-assets/review-image-assets/SKILL.md) 追查。后端/模型参数只在它们影响当前要求或真实性时核对，不用一套通用提示词规则评判所有模型，也不拿参数看似正确代替成图。

缺少实际素材、观察能力或对应证据时，明确哪些判断仍待核对。纯画风偏好与偏离用户已确认基准分开；前者是建议，后者有具体对照才成为缺陷。既有基准下的普通图不增加逐张用户审批门槛。
