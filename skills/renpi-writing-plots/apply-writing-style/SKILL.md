# 应用文风

这是 v0 可替换占位模块，目标是让当前单元写得一致、人物说话有区别，而非建立文风百科。正文质量优先于可运行脚本；本模块只交付文风档。

## 进入条件

先沿用主入口的路由与 [Writing 共享契约](../references/writing-contract.md)。本模块位于“读取已知内容 → 粗纲 → **文风** → 修订细纲 → 基础 RPY → 文本记忆”的自由创作分支。

- 当前单元有明确原文待忠实改编：跳过本模块及其参考，不加载通用文风、反八股或禁词规则去改写原文。
- 只有世界观、角色设定或前情：这些是创作约束，不等于已有可改编原文；按主入口认定的自由创作范围使用本模块。

## 工作与交付

1. 读取当前粗纲、用户本轮要求与既有文风档。已确定项直接复用；用户新要求仅覆盖冲突项，保留其余决定。
2. 首次建档，或人称、玩家代言、倾向、禁词有缺项或调整时，读取 [v0 文风占位参考](references/style-placeholder.md) 中相关部分。无需每轮重读或重复问卷；低影响缺项可轻量暂定并显式标注。重大方向分歧汇报 Coding，保留未冲突部分。
3. 交付参考所示小型文风档给细纲修订与正文阶段，标明适用单元、复用项、本轮变更和暂定项。完成标准：人称与知情边界、对话密度、三类玩家代言、倾向、硬约束与软提示均有明确值或标记。
4. 下游按文风档调整叙述、对话与表现方式，保持粗纲已确定的事件和人物动机；发现冲突则反馈细纲修订，而非用措辞掩盖。文风决定与待确认项留在文风档，文本记忆只引用适用版本，不将暂定偏好升级为永久规则。
