# 文风占位参考 v0

本文件是可整块替换的轻量初版，不代表完整文风体系或外部研究结论。替换时保留文风档交付字段与主入口的原文路由边界；自由创作才读取本文件。

## 人称与知情边界

- **第一人称**：明确“我”是谁。叙述以其感知、记忆与推测为限，推测保持不确定性。
- **第二人称**：明确“你”指玩家还是其他受述者。代词本身不授予替玩家做决定或编写内心的权限。
- **第三人称**：写清聚焦人物与限知或全知。全知须是已选定的叙事方式，而非方便泄露伏笔的借口。
- 场景中切换视角时给出可辨认的分隔或转场；角色所知、读者所知、作者已知分别处理。人称没有既定选择时可暂用第三人称限知，并标记聚焦对象待定或依据。

## 对话密度

以少／中／多表达倾向，不机械凑比例：少偏重动作、环境与叙述；中让叙述和对话互相推进；多让人物交锋承担较多推进，但保留必要动作与场景定位。随场景目的调整，以事件推进和人物表达有效为准。缺省可暂用“中”。

## 玩家代言分三项

分别记录**台词、动作、想法**，不要用一个“代言开关”包办。

- 默认将未确认的玩家台词、关键自主决定与主观想法留给玩家；仅呈现已确立的外部事实和必要客观反应。
- 用户明确给出的台词、动作、意图或想法可忠实呈现；表现性扩写也应留在该输入的意义内。
- 用户可分别允许某类代写，并说明范围。例如允许行走、观察等过渡动作，不自动包含接受约定、攻击或表白等自主决定；允许动作也不自动允许台词或内心。
- 第二人称的“你爱上了她”同样是在代写想法，第三人称称呼玩家角色也遵守同一边界。

## 可组合的倾向

以下是本轮表达方向，不是固定流派定义；组合时写清各自作用，冲突时以用户优先项为准。

| 用户用词 | 本版暂用的操作提示 |
| --- | --- |
| 平然 | 保留用户原词，暂按“平实自然”理解；少摆姿态，以具体感受和自然句序表达。 |
| 白描 | 用可观察的动作、物件和少量关键细节承载意味，留出解释空间。 |
| 网文 | 重视阅读推进、信息释放与当前悬念，按本故事节奏使用，非每段制造钩子。 |
| 综漫 | 在已知设定内处理角色互动与语境差异，既有角色保持自身声线；不凭标签补设定或塞梗。 |
| 轻小说 | 可偏重角色感、对话节奏与贴近视角的感受，吐槽是否采用取决于人物。 |
| 舞台剧 | 可偏重场上行动、台词交锋和停顿，让可见可听的变化承担戏剧效果。 |

无既定偏好时可暂用“平然（暂按平实自然）”，而非一次叠满全部标签。

## 反八股与词语约束

反八股检查的是表达是否服务当前情境：空泛升华是否有具体事件支撑，固定句式是否反复替代观察，各角色是否共用万能人物声线。优先改为人物此刻会注意的细节、会选择的措辞与有来由的停顿；保留有意的回环、呼应和角色口头禅，不把“去八股”变成另一套统一腔调。

- **硬约束**：只收录用户明确禁止的词语或句式，记录适用范围、理由（如已给出）及明确例外；默认空表。
- **软提示**：记录“少用、慎用、在某情境避开”等偏好，按上下文判断；默认空表。
- 常见词、连接词、比喻等不因单次不佳使用而永久禁用。逐处语义检查，避免全局替换损坏人名、专名、引文或人物口头禅；硬约束与必须保留的文本冲突时，标明冲突并汇报 Coding，由其协调取舍。

## 小型文风档

用短条目交付，已有档案只报告变化。各项状态用“已定／复用／暂定／待协调”区分。

```text
适用：当前单元或场景；自由创作范围
人称与知情：第一／第二／第三；叙述者或聚焦对象；限知／全知；切换方式
对话：少／中／多；场景内允许的调整
玩家台词：允许范围（默认仅忠实呈现明确输入）
玩家动作：允许范围（关键自主决定默认留给玩家）
玩家想法：允许范围（默认仅忠实呈现明确输入）
倾向：选用词与组合分工；“平然”的本轮理解
人物声线：本场有差异需求的角色，各记一个具体表达特征
用户硬约束：[]；有条目时写适用范围与明确例外
偏好软提示：[]
本轮变化与状态：复用哪些；新增或暂定哪些；待 Coding 协调什么
```

交付前检查：同一句叙述是否越过视角知情边界或玩家代言范围；人物是否有自己的表达理由；禁词是否确为用户约束。已定风格仍适用且各项齐全时直接交接，不额外生成问卷或示范篇章。
