# 写粗略剧情大纲

进入条件：[读取已知文本](../read-plot-context/SKILL.md) 已完成，本轮属于自由创作。已有仍适用的纲直接续用或局部调整；原文改编范围直接转到正文。

## 写什么

先用一句话说明本轮从什么局面走到什么局面，再写足以支撑本轮的几个情节节点，不预先铺完未知整部作品。

每个节点说清：人物想做什么、遇到什么条件或阻力、为何采取行动、结果如何改变局面，以及它为何引出下一节点。平静场景也可以靠信息、关系或行动目标发生变化，避免硬塞冲突、反转或悬念。

- 从有效前情与本次玩家输入出发，尊重人物当前掌握的信息及能力；需要的新设定标成拟新增，而不是伪装为既有设定。
- 区分本轮必经事件、可选提案与留给玩家的决定。到达选择点时给出选择语义或待输入问题，后果只作备选构思，不写成已经选定。
- 写出结尾的自然交接位置及保留问题。用户已限定篇幅/节奏时遵守，但不靠固定字数截断因果。
- 通常保留一个可执行方案；只有真实方向分歧才给少量有区别的选择。已有委托内的日常情节细节由 Writing 决定。

## 交付与检查

粗纲保留“起点—事件骨架—本轮变化—停止点”，附所依赖的关键前情与拟新增项。检查人物动机、因果和玩家控制边界，避免用气氛形容词替代事件。

完成标准：从当前局面到本轮停止位置有连贯且可展开的事件路径，尚未决定的玩家行动仍然开放。交给 [文风指导](../apply-writing-style/SKILL.md)，再据其结果修订细纲；粗纲是工作稿，不自动成为既定剧情事实。
