# 读取已知文本

进入条件：Coding 已给出本轮目标、任务要求和可写范围。先读 [Writing 边界](../references/writing-contract.md)，本阶段以读取为主。

## 按本轮问题读取

1. 读取用户本次要求、制作范围和停止点，确认用户是在阅读还是扮演、已经选择/输入了什么。继承已明确的代玩家说话等约束，不从第二人称称谓推导玩家授权。
2. 读取当前全局依据及目标 flow 上适用的分支资料增补。先用索引定位，再看与本轮人物、地点、事件、时间有关的原文；最新修改时间不是采用依据。
3. 读取接续位置之前的有效剧情和上一轮文本记录。对关键台词、承诺、悬念、物件去向及角色知情状态回查正文，摘要与正文不一致时记下冲突，避免只信摘要。
4. 有原文改编时完整读取本轮选定范围，并看足够的前后文以辨认说话者、指代和自然场景边界；多个分片连续读取到范围末尾，分片结束不等于剧情结束。只有设定或剧情摘要时按自由创作处理，不伪称忠实改编已有正文。
5. 将未来原文信息、人物猜测与当前路线已发生事件区分开；其他分支、已取消结果、被重试替代的后续仅在明确需要时作为参考，带来源标识。

大资料按索引逐段读取，记录已读与未读范围。先读本轮必需内容，远期无关资料保留引用即可；检索片段不证明整章已读。必需来源缺失或内容含义冲突时，携具体路径/位置交回 Coding。

## 形成工作底稿

复用任务说明或产出短小的上下文底稿，包含：

- 本轮模式：原文改编、自由创作，或已明确分段的混合；采用依据及位置引用。
- 起点与停止边界、当前有效前情、本次用户行动，以及确定的玩家控制范围。
- 本轮相关人物的目标/关系/知情状态、场景位置与未解事项；客观事实、角色误认、读者已知分开标记。
- 仍适用的风格或特殊文本要求，真正缺失的输入和已读覆盖范围。

完成标准：足以从确定位置接续，关键事实有来源，必需内容已读且模式明确。返回 [入口路由](../write-plots/SKILL.md#先读取再分路)：原文路线直接交基础 RPY，自由创作先交粗纲。
